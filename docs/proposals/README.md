# 検討中の設計案

このフォルダには、まだ実装されていない検討中の設計案を置く。
実装が完了し本番に反映されたら、該当する内容を docs/spec.md へ統合し、
このフォルダのファイルは削除するか「実装済み」に更新すること。

docs/spec.md との違い：
- docs/spec.md　　　　　　：実装済みの正本。ここに書かれた内容は本番で動いている
- docs/proposals/ 配下　　：検討中・未実装。方針であり、まだ動いていない

例外：作業記録（参考資料）も置く（例：demo-cleanup-2026-10-07.md＝本番デモデータ削除の記録。実行用ではなく、次回の作業の土台）。これらは上記の「実装完了後に削除・更新」の対象外。

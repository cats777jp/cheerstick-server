# お客様（業販先）向け管理画面の認証・データ範囲の限定

管理画面UI刷新（`docs/proposals/admin-ui-redesign.md`は未作成。刷新自体は段階的に実装中）の
目的の一つは、将来お客様に管理画面を使っていただくことだが、**デザイン（ui.css／brand.css）
だけではお客様に渡せる状態にならない。** 以下は別項目として扱う。

## 現状（2026-10-27時点）

- 管理画面（`admin.cheerstick.com`）・管理API（`api.cheerstick.com/api/v1/admin/`）とも、
  アプリケーションレベルの認証は無い。nginxのIP制限（`49.156.217.121`のみ許可）が唯一の防御
  （`docs/runbook.md`「管理API アクセス制限」参照）
- 管理APIは全チーム（organizations）のデータを返す。お客様ごとに見える範囲を絞る仕組みは無い
- したがって、お客様のIPを許可リストに足しただけでは、他のお客様のデータも見える・操作できてしまう

## 検討が必要な項目（未決定）

1. ログイン機構（nginx Basic認証の暫定運用か、アプリ側のログインか）
2. お客様アカウントと organization の紐付け、管理APIでのデータ範囲の限定
3. 操作権限の区分（閲覧のみ／試合操作のみ／マスタ編集 等）
4. 許可IPの運用（お客様ごとのIP、VPN）
5. 操作ログ（誰がいつ試合状態を変えたか）

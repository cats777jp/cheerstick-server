## 2. 2026-07-28に確定した技術仕様

### 2.1 JSブリッジ（Vanstone様回答＋原本HTMLで確定）

**アプリ → WebView**

```
入口: receiveFromApp(jsonString)   ← 改名しない。APP側の改修を避けるため
```

**WebView → アプリ**

```javascript
iOS     : window.webkit.messageHandlers.myBridge.postMessage(jsonString)
Android : window.androidBridge.postMessage(jsonString)
```

**重要な実装上の注意**

- 送信経路は**1本のみ**。`stat` フィールドが実質のメッセージ種別
- **全て jsonString**（JSON.stringify / JSON.parse を挟む）
- **Androidのブリッジは非同期注入**される。起動時に判定を固定せず、
  **送信のたびに判定すること**（原本HTML末尾 `setTimeout(updatePlatformUI, 500)` が根拠）
- `window.CheerStickBridge` は**アプリ側に存在しない。**KMT側で定義する名前

**ペイロード**

| 用途 | 形式 |
|---|---|
| LED制御 | `{"LED":{"r":r,"g":g,"b":b},"stat":"OK"}` |
| BLE再接続要求 | `{"LED":{"r":0,"g":0,"b":0},"stat":"BleRetry"}` |
| 参照URL連携 | `{"stat":"connect","url":"<reference_url>"}` |
| 終了通知 | `{"stat":"end"}` → **アプリが終了する**（仕様書に明記） |

### 2.2 LED形式は「オブジェクト」で確定

配列 `[R,G,B]` 表記は**仕様書内の手書き略記**であり、仕様ではない。

| 出典 | 形式 |
|---|---|
| 6/30仕様書 LEDセクション | オブジェクト（半角括弧・引用符あり＝JSON記法） |
| Vanstone様テスト用HTML 1259/1314行 | オブジェクト（切断時含む） |
| 6/30仕様書 第7項 | `｛LED:[R,G,B]｝`（**全角括弧・引用符なし＝略記**） |

### 2.3 その他の確定事項

| 項目 | 内容 |
|---|---|
| `num` | **連番カウンタ。デバイス識別子ではない。**`0` はBLE切断のセンチネル |
| デバイス識別 | URLパラメータ `?id={MACアドレス}` |
| `accel` | 通常10サンプル、BLE切断時1サンプル。**要素数を仮定しないこと** |
| 送信間隔 | 約1秒（仕様書コメントに明記） |
| `volt` | `3.0` 以下で「電池残少」表示 |
| 輝度制御 | **不要。**PWMによりRGB値で調整される |
| 接続直後のLED | **不要。**デバイスは電源ONで待機色に点灯。振動まで無点灯で可 |

### 2.4 応援量カウント算出（旧実装）

```
各軸のサンプルのうち |値| > 25 の個数を3軸分合算
　→ 合計を最後に一度だけ Math.min(count, 21) でクランプ
```

詳細は `docs/proposals/cheer-count-algorithm.md`（コミット済み）。
Vanstone様へメール添付済み。
